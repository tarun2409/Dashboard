# 📊 Dashboard Project 1 – Power BI

## 📌 Project Overview

This project is an interactive **Power BI Dashboard** developed to transform raw business data into meaningful insights through visual analytics. The dashboard provides a clean and user-friendly interface that helps users monitor key performance indicators (KPIs), analyze trends, and make data-driven decisions.

---

## 🎯 Objective

The objective of this project is to:

- Convert raw data into interactive visual reports
- Monitor important business KPIs
- Identify trends and patterns
- Support better business decision-making
- Demonstrate Power BI dashboard development skills

---

## 📈 Dashboard Features

- 📌 KPI Cards
- 📊 Bar Charts
- 📈 Line Charts
- 🥧 Pie/Donut Charts
- 📅 Time-Based Analysis
- 🎛 Interactive Slicers
- 📍 Dynamic Filters
- 📋 Summary Dashboard
